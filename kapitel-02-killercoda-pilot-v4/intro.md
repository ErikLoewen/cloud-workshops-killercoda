# Kapitel 02 – Killercoda-Technikpilot V4

Dieser Pilot folgt nun demselben Startmuster wie die funktionierenden Workshops
aus Kapitel 1:

- `setup.sh` läuft direkt als Intro-Foreground;
- das Setup ist vollständig selbstständig;
- es gibt keinen Asset-Entry, kein Runtime-Archiv und keinen Warter unter `/tmp`;
- das Setup endet im vorbereiteten Arbeitskonto `telegrafist`.

Der erste Schritt kombiniert robuste interaktive Markdown-Bereiche mit einer
lokalen HTML/CSS/JavaScript-Web-App. Inline-JavaScript im Killercoda-Text wird
nicht vorausgesetzt.
