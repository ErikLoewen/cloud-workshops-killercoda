# Eine alte Abschrift entfernen

`rm` entfernt hier eine einzelne, eindeutig entbehrliche Datei. Es gibt in
diesem Ablauf keinen Papierkorb.

Prüfe vor dem Löschen Standort und Ziel:

```bash
pwd
ls arbeitstisch/alte-abschrift.txt
```

Sage voraus, was fehlen und was erhalten bleiben soll. Tippe dann selbst:

`rm arbeitstisch/alte-abschrift.txt`{{}}

Kontrolliere das Ergebnis mit `ls arbeitstisch`. Das Original, die Sicherung,
die volle Kiste und die eingestürzte Ecke dürfen dadurch nicht betroffen sein.
