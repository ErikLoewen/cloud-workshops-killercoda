# Schritt 2: Das blinkende Signal – Prompt und Terminal

Der Bildschirm im Wärterraum ist nicht eingefroren. Vor der Eingabestelle
steht der **Prompt**. Er kann etwa so aussehen:

```text
root@host:~#
```

Die genaue Darstellung kann bei dir etwas anders sein. Du musst diese Zeichen
weder verstehen noch mittippen.

## Woran erkennst du die Bereitschaft?

Ist der Prompt sichtbar, wartet die Shell auf deine nächste Eingabe. Nach
einem fertigen Befehl erscheint er wieder. Fehlt er, läuft möglicherweise
noch etwas. Später in diesem Workshop probierst du das gefahrlos aus.

## Terminal bereit machen

1. Klicke einmal in den Terminalbereich.
2. Suche den Prompt.
3. Achte auf die Eingabestelle direkt dahinter.

Mit **Enter** führst du eine fertige Eingabe aus.

## Text kopieren und einfügen

- **Kopieren:** Text markieren, dann **Strg+Umschalt+C** drücken.
- **Einfügen:** Hinter den Prompt klicken, dann **Strg+Umschalt+V** drücken.

Auf manchen Tastaturen steht **Ctrl** statt **Strg** und **Shift** statt
**Umschalt**. Prüfe vor dem Einfügen kurz, ob der Prompt sichtbar ist.

## Eingabe, Ausgabe, Fehlermeldung

Die Shell antwortet auf unterschiedliche Weise:

- **Eingabe:** Das tippst du hinter den Prompt.
- **Ausgabe:** Das Ergebnis eines Befehls.
- **Fehlermeldung:** Eine Rückmeldung, wenn die Shell etwas nicht ausführen
  konnte.

Eine Fehlermeldung gehört zur Arbeit im Terminal. Sie bedeutet nicht
automatisch, dass etwas beschädigt wurde.

## Merksatz

**Prompt sichtbar: Die Shell ist bereit für eine neue Eingabe.**
