# Kapitel 02 – Killercoda-Technikpilot V3

V3 behebt den Assetpfad vollständig: Killercoda lädt Szenario-Assets
ausschließlich aus dem Unterordner `assets/`.

Der Pilot prüft:

- den sicheren Asset-Upload;
- den Start von `xebico-dienst`;
- interaktive `<details>`-Demonstrationen im Text;
- eine lokale HTML/CSS/JavaScript-Netzwerkarchitektur;
- Ports, Bindung, HTTP, Namensauflösung und Traffic-Pfad.

Inline-JavaScript im Markdown wird nicht mehr vorausgesetzt.
