# Die letzte Nachricht ausführen

Untersuche `letzte-nachricht`:

```bash
ls -l letzte-nachricht
./letzte-nachricht
```

Auch diese eigene Datei ist zunächst nicht ausführbar. Ergänze nur das
Besitzer-Ausführungsrecht, kontrolliere es und führe sie erneut aus:

```bash
chmod u+x letzte-nachricht
ls -l letzte-nachricht
./letzte-nachricht
```

Die Schalttafel gibt jetzt die letzte Spur als Flag aus. Kopiere den
vollständigen Text für die Abschlussprüfung.
